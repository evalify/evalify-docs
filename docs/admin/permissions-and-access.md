# Permissions and Access

Control access to the admin panel and features using Roles.

## Available Roles

| Role | Description |
| :--- | :--- |
| **Admin** | Full system access. Can manage users, configuration, logs, and all system settings. |
| **Manager** | Oversees academic operations. Can manage batches, semesters, and view reports but has limited system config access. |
| **Faculty** | restricted to academic duties. Can view assigned courses, manage quizzes, and students. |
| **Student** | Limited access. Can view their own profile, enrolled courses, quizzes, and results. |

## Changing Permissions
To change a user's role, navigate to the [Users](./config/user-creation.md) page and edit the user profile.
