# User Creation

Manage application users, including students, staff, and administrators.

![User List Interface](/img/admin/user/users.png)

## Viewing Users
The user list displays all registered accounts. You can search for users or filter them by role and status.

## Creating a New User
To add a new user, click the **"Create User"** button.

![User Creation Form](/img/admin/user/user-creation.png)

### Steps
1.  **Username**: Enter a unique username.
2.  **Email**: Provide a valid email address.
3.  **Role**: Assign the appropriate role (e.g., Student, Staff).
4.  **Password**: Set an initial password.
5.  Click **Save** to create the account.
