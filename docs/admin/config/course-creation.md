# Course Creation

Define the courses offered by the departments.

![Course List](/img/admin/course/course.png)

## Adding a Course
1. Navigate to the **Course Configuration** section.
2. Click **"Create Course"**.

![Course Creation Form](/img/admin/course/course-creation.png)

3. Enter details:
    - **Course Title**: e.g., "Data Structures".
    - **Course Code**: e.g., "CS-101".
    - **Credits**: Number of credit hours.
    - **Department**: Owning department.

## Assigning to Semesters
Once created, courses can be mapped to specific semesters and batches in the Curriculum settings.
