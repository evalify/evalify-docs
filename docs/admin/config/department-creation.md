# Department Creation

Manage the academic departments within the institution.

![Department Configuration](/img/admin/department/department.png)

## Adding a Department
To register a new department, click **"Add Department"**.

![Department Creation Form](/img/admin/department/department-creation.png)

### Required Fields
- **Name**: Full name of the department (e.g., Computer Science).
- **Code**: Short code (e.g., CS, IT).
- **Head of Department**: Select the HoD from existing staff.

## Editing Departments
Click the edit icon on any department row to update its details or change its active status.
