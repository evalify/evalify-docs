# Batch Creation

Batches group students together for academic sessions.

![Batches List](/img/admin/batches/batches.png)

## Overview
The Batches page lists all active and past batches.

## creating a Batch
Click **"Create Batch"** to start.

![Batch Creation Form](/img/admin/batches/batch-creation.png)

### Configuration
- **Batch Name**: e.g., "2024-2028".
- **Department**: Link the batch to a specific department.
- **Advisor**: Assign a staff advisor if applicable.

## Managing Students
You can manage students within a specific batch.

![Batch Student Management](/img/admin/batches/batch-manage-students.png)

- **Add Students**: Bulk upload or select existing students.
- **Remove**: Remove students from the batch.: 3
