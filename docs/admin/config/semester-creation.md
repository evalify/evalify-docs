# Semester Creation

Define academic semesters and associate them with batches.

![Semesters Overview](/img/admin/semester/semester.png)

## Single Semester Creation
Use the **"Create Semester"** form to add one semester at a time.

![Create Semester Form](/img/admin/semester/semester-creation.png)

- **Name**: e.g., "Fall 2024".
- **Start/End Date**: Define the duration.

## Bulk Creation
For efficiency, you can generate multiple semesters at once.

![Bulk Semester Creation](/img/admin/semester/bulk-create-semester.png)

- **Pattern**: Define the naming pattern (e.g., "Semester 1").
- **Count**: Number of semesters to generate.
- **Duration**: Default duration for each.
