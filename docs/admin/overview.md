# Admin Overview

The Admin Dashboard provides a centralized view of the application's health and activity.

![Admin Dashboard](/img/admin/dashboard.png)

## Features
- **Management**: Create and manage Users, Batches, Semesters, Courses, Labs, and Departments.
- **Key Metrics**: View total users, active sessions, and system health status.
- **Traffic Analysis**: Monitor application traffic trends over time.
- **Recent Activity**: Track the latest actions performed within the system.

Navigate to specific sections using the sidebar to manage users, view logs, or configure permissions.
