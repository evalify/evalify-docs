# Report an Issue

We welcome feedback and bug reports to help improve Evalify. If you encounter any issues or have suggestions for new features, please report them on our GitHub repository.

## How to Report an Issue

1.  Go to the [Evalify GitHub Issues](https://github.com/evalify/evalify/issues) page.
2.  Click on the **New issue** button.
3.  Choose the appropriate template (Bug Report or Feature Request) if available, or start a blank issue.

## Issue Template

When reporting a bug, please include the following information to help us resolve it quickly:

### 1. Description
A clear and concise description of what the bug is.

### 2. Steps to Reproduce
Steps to reproduce the behavior:
1.  Go to '...'
2.  Click on '....'
3.  Scroll down to '....'
4.  See error

### 3. Expected Behavior
A clear and concise description of what you expected to happen.

### 4. Screenshots
If applicable, add screenshots to help explain your problem.

### 5. Environment
-   **OS:** [e.g. macOS, Windows]
-   **Browser:** [e.g. Chrome, Safari]
-   **Version:** [e.g. 1.0.0]

## Request a Feature

We love hearing about new ideas! To request a feature:

1.  Go to the [Evalify GitHub Issues](https://github.com/evalify/evalify/issues) page.
2.  Click on **New issue**.
3.  Select **Feature Request**.

## Feature Request Template

Please include the following details:

### 1. Is your feature request related to a problem?
A clear and concise description of what the problem is. Ex. I'm always frustrated when [...]

### 2. Describe the solution you'd like
A clear and concise description of what you want to happen.

### 3. Describe alternatives you've considered
A clear and concise description of any alternative solutions or features you've considered.

### 4. Additional Context
Add any other context or screenshots about the feature request here.
